# Gerenciamento de E-Commerce

## Identificação
* **Estudante:** Daniel Puerari
* **Turma:** Node-T5

## Objetivo da Aplicação
Um sistema de gerenciamento de e-commerce que permite cadastrar produtos, controlar o estoque, montar carrinhos de compras, registrar pedidos e acompanhar os resultados das vendas. O sistema precisa manter as informações organizadas e reduzir erros comuns, como vender produtos sem estoque suficiente, calcular valores incorretamente ou registrar pedidos incompletos.
